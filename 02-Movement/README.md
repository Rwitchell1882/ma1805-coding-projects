I chose this project to be about WW2 because I wanted to be able to visualise an event with a high death toll. This death toll is represented by a word appearing on the screen each time someone died in WW2 (≈ 2 seconds). The words are arranged rigidly into columns, however, the yellow lines, which represent bullets, are completely random. These bullets may miss, graze or go straight through the words, just like they would a soldier, symbolising the unpredictable violence of war. The hardest part was arranging the words into collums as I had move the text horizontally before resetting it's x coordinate to the row below.
